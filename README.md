# 🌌 Aetheris — Modern E-Commerce Platform

Aetheris — это современная платформа электронной коммерции с уникальным дизайном в стиле **Glassmorphism**. Проект включает в себя полноценную систему аутентификации, профили пользователей и адаптивный интерфейс.

## ✨ Особенности
* 🖥️ **Glassmorphism UI**: Стильный, полупрозрачный интерфейс.
* 🔐 **Supabase Auth**: Безопасная регистрация и вход через Email и OTP.
* 👤 **User Profiles**: Двухэтапная регистрация и возможность редактирования данных.
* 📱 **Responsive**: Полная адаптивность под мобильные устройства.

## 🛠️ Технологии
* **Frontend:** HTML5, CSS3 (Flexbox/Grid), JavaScript (ES6+).
* **Backend:** Supabase (Database & Auth).
* **Icons:** FontAwesome.
