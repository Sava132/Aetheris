# 🌌 Aetheris — Modern E-Commerce Platform

Aetheris is a sleek, next-generation e-commerce platform featuring a unique **Glassmorphism** design. This project includes a robust authentication system, customizable user profiles, and a fully responsive interface.

---

## ✨ Features
* 🖥️ **Glassmorphism UI**: High-end, translucent user interface with modern aesthetics.
* 🔐 **Supabase Auth**: Secure registration and login using Email and OTP (One-Time Password).
* 👤 **User Profiles**: Two-step registration process with the ability to edit user data post-signup.
* 📱 **Fully Responsive**: Optimized for all devices, from desktops to mobile phones.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3 (Flexbox/Grid), JavaScript (ES6+).
* **Backend:** Supabase (Database & Authentication).
* **Icons:** FontAwesome.
